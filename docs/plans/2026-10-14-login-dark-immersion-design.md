# 登录页全屏深色沉浸 · 设计文档

日期：2026-10-14 · 分支：`feature/login-dark-immersion` · 状态：已确认

## 背景

当前登录页为「左深右浅」双栏：右侧大面积浅灰留白，登录卡视觉重量不足；底部能力条字号偏小；表单缺密码可见性等细节。目标是在不破坏现有动效体系（`motion.ts`、无幕交接、开场编排）的前提下整体提升视觉。

## 方案

### 1. 布局架构

- `.login` 从双栏改为**单一全屏深色画布**：NeuralNet 铺满视口，密度下调约 30%，画布叠加左下→右上暗色渐变 scrim 保证文字可读性。
- 左侧约 58%：品牌区 → 文案 → 时钟表盘，字号与留白放大。
- 右侧：登录卡改**深色玻璃质感**（白 6% 透明底 + backdrop-blur + 1px 白边 + 顶部内高光），宽 400px，垂直居中；保留指针倾斜与 glow 跟随。
- 底部能力条改**通栏玻璃条**（四项能力 + 服务健康合并），title 13.5px / desc 12px。
- 登录页在明/暗主题下均保持深色（品牌门面页，不进主题切换），改动只落在 `.login` 作用域。

### 2. 表单交互细节

- TextInput 增加尾部插槽，密码框内嵌眼睛图标切换可见性。
- 验证码输入框与验证码图合成一体控件（共享外框，左右圆角）。
- 接口级错误改玻璃警示条（左竖红线 + alert 图标），失败时登录卡轻微水平抖动。
- 「记住登录状态」整行可点（Checkbox 已是 label 包裹，确认即可）。

### 3. 动效增强

- 时钟点亮刻度叠加呼吸光晕（1.6s 循环，`prefers-reduced-motion` 跳过）。
- 入场编排选择器随结构类名更新；NeuralNet burst 成功脉冲保留。

### 4. 响应式与验收

- ≥1200px 完整双区；900–1200px 隐藏表盘；<900px 隐藏左画布、纯深色底 + 居中卡。
- 验收：vue-tsc + build 通过；CDP 截图 2560/1440/375 三档；登录成功 / 失败 / 换验证码三路径；changelog.md 更新。

## 风险

- 全屏深色下文案可读性 → scrim 渐变 + 粒子密度下调。
- `m-glow` / `trackGlow` 原为浅卡设计 → 出深色变体。
- 无幕交接依赖「舞台底不动」→ 只改面板与卡片，不动 `--stage` 根基。
