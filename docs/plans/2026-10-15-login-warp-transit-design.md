# 登录转场特效设计：消散 → 曲率穿越 → 星体脱出

日期：2026-10-15 · 分支：feature/login-dark-immersion · 状态：已确认实施

## 背景

2026-10-15 修复登录转场闪黑时，把登录页退场终点从「全黑」桥接为 `--stage` 舞台底，
在浅色主题下用户读作「闪白」，且反馈「转场太干」。用户明确要特效（粒子消散 / 穿越银河系），
并选定：**先消散后穿越 + 压缩对勾 + 星体脱出接管欢迎链**。

历史约束：登录转场曾两次否决「幕」（不透明遮盖层）。本设计的特效层是**透明 additive 的画布
+ 暗色天幕**，页面本体（登录页消散、外壳组装）始终真实在场，天幕是「银河本身」而非遮盖物。

## 叙事与时间线（点击起算，总长约 6.5s）

| 时刻 | 段落 | 内容 |
|---|---|---|
| 0 → ~1.0s | 对勾（压缩版） | 按钮收成圆、圆环描出、对勾画出，描完即走，砍掉回弹尾巴（省 ~0.5s） |
| ~1.0 → 1.55s | 消散 | 品牌文案、表盘、登录卡按元素矩形采样出粒子向上飘散；DOM 本体 0.35s 快速淡出；暗色天幕 0.3s 淡入 |
| ~1.55 → 2.5s | 曲率穿越 | 星点从中心向外拉成光丝加速（先加速后减速 ~0.9s）；路由在加速段中段切换，外壳在暗场下组装 |
| ~2.5 → 2.9s | 星体脱出 | 减速时最亮的星沿弧线飞到 `(vw-150, 116)`——欢迎链星球坠落起点；到达即 `release`，天幕 0.5s 抬起 |
| ~2.9s 起 | 欢迎链接管 | 星球在落点出现、坠落、炸开、打字、归位；WelcomeChain 原样复用，仅从「等待 release」开始 |

## 架构

- 新增 `keystone-vue/src/components/welcome/WarpTransit.vue`（Teleport body，z-80，pointer-events: none）：
  - 天幕 div：近黑径向渐变 + 青柠/蓝星云晕，负责防闪（穿越全程暗场）；
  - 全屏 canvas：消散粒子 + warp 光丝 + 脱出星体，走 `createFrameLoop`/`gsap` 基建，粒子设上限。
- **挂在 App.vue**：特效层必须活着跨过路由切换（Login 切换时卸载，Teleport 内容随之销毁）。
- 配色复用欢迎链：白星为主、约 30% 青柠、少量蓝；明/暗主题同用暗场（银河本身暗）。

## 状态机（`composables/welcome.ts` 扩展）

- 新增 `transitActive` / `transitReleased` 两个 ref。
- `beginHandoff()` 置 `transitActive=true`；减少动态效果/页面在后台时特效不启动（维持直切）。
- WelcomeChain `onMounted` 先等 `transitReleased`（轮询 + 3s 超时兜底）；星球坠落起点坐标不动，
  脱出星到达同一坐标后 80ms 内星球出现——视觉上是同一个天体。
- `ARRIVE_BUDGET` 3600 → 4200；WarpTransit 自带 6s 安全阀自卸（置 `transitActive=false` + `transitReleased=true`）。

## 失败与降级

- 导航失败/会话过期（现有路径）：`restoreLoginStage()` 还原面板、`transitActive=false` 天幕快速淡出。
- 减少动态/后台：特效整体跳过；`preloadHome()` chunk 预取保留（2026-10-15 上次的修复成果继续生效）。
- 回退 2026-10-15 的「登录根底色淡出到 `--stage`」：天幕接管防闪职责，根底色不再处理。
