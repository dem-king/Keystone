# 退出登录动效设计方案：把「离开」做成一次收拢

> 状态：**已实施（2026-10-19）**。落点：`composables/exit.ts`、`components/welcome/ExitChain.vue`、`App.vue`、`AppShell.vue`、`auth.ts`（`logout({ keepSession })`）、`Login.vue`（`playExitArrive`）、`styles/pages.css`。
> 验证脚本：`keystone-vue/scripts/verify-exit.mjs`（抽名 / 天幕 / 切页时序 / 登录页浮现 五项断言）。实测：暗场 clip 半径第 115 帧覆盖全屏，路径第 147 帧才切到 `/login`——先暗后切，符合 §4.2。
>
> **实施后返工的两处（用户反馈「像加了一层遮罩，没有效果」）**：
> 1. 天幕不再整层淡入——那就是遮罩。改成 `clip-path: circle(0 → 1463px at 50% 50%)` 从光点位置向外炸开，0.68s。
> 2. 页面收拢不再用 `filter: brightness(0.55)`（读作盖灰）。改成 `opacity → 0.12 + scale 0.97`，同时从每张卡片、每组导航各飞出 2 颗碎屑被胶囊吸走（实测 46 颗）。
> 3. 标题不能直接改 DOM：Vue 的 vdom 还是 `{{ greeting }}，{{ name }}`，任何 patch 都会把拆好的 span 冲掉（0.9s 后标题又变完整）。改成在标题位置盖一层克隆、真实标题 `opacity: 0`。

## 1. 一句话

工作台不散开、不淡出，而是**向内收拢**：标题里的名字先被抽走飞回右上角的你，你接住它、缩成一颗光点，光点飞向中央撕开暗场，登录页从暗场里重新组装出来。

这是入场的镜像——入场是「从你身上出发，落到工作里」，退场是「从工作里收回，回到你身上」。

## 2. 为什么不做「倒放」

把欢迎链倒着播一遍最省事，但会露馅：入场所有缓动都是「快起慢收」（`expo/power.out`），倒放就变成「慢起快收」，读作「被倒带」；粒子方向、光丝推进方向也都要反，逐条改的工作量并不比新写少。更重要的是**语义不对**：退出不是「回到登录前的状态」，是「把这一场收起来」。

## 3. 分镜（2.75s）

| # | 段 | 起 | 时长 | 画面 | 缓动 |
| --- | --- | --- | --- | --- | --- |

| E0 | 停顿 | 0.00 | 0.12 | 确认弹窗关闭后画面静止一拍；右上角胶囊浮起一层极淡的呼吸光（「要走了」） | `power1.out` |
| E1 | 抽名 | 0.12 | 0.50 | 页头标题里的**用户名部分**先变淡、字距收紧 0.04em，随即粒子化（12~16 颗）沿左上到右上的弧线飞向胶囊；「下午好，」原地留到 E3 | `power2.in` |
| E2 | 接住 | 0.62 | 0.28 | 胶囊头像脉冲一圈光环（`scale 0.6 → 1.6`，0.36s 淡出），胶囊轻放大 `1 → 1.04 → 1` | `back.out(2.4)` |
| E3 | 收拢 | 0.90 | 0.50 | 导航组与工作台卡片向画面中心位移 6px、亮度降到 0.55（不是消失，是被吸住）；四周粒子向胶囊汇聚（`sprayIn`） | `power2.inOut` |

**净增等待 2.75s**。比入场的 12.6s 短一个量级——离开不需要那么隆重的仪式。

## 4. 架构

```
AppShell.onLogout()
  └─ confirm → beginExit()            ← 进入退场态，装点击拦截
     └─ playExit()                     ← ExitChain 编舞（E1~E5），播完 resolve
        └─ clearSession()              ← 此时才清 token / 菜单 / 动态路由
           └─ router.replace('/login')
              └─ Login.vue onMounted   ← 检测 exitActive → 跳过 intro，直接「从暗场浮现」
                 └─ finishExit()       ← 天幕抬起、卸层、解拦截
```

### 4.1 新文件

| 文件 | 职责 |
| --- | --- |
| `composables/exit.ts` | `exitActive / exitPhase / exitSwapped` 三个信号 + `beginExit / markExitSwapped / finishExit`；与 `welcome.ts` 的 handoff 完全独立，互不复用状态 |
| `components/welcome/ExitChain.vue` | E1~E5 的 DOM 编舞：抽名粒子、胶囊脉冲、收拢、成点、起飞；`Teleport` 到 body，`z-index: 90`，`pointer-events: none` |
| `WarpTransit` 加 `mode` | `mode="out"`：天幕从 0 铺到 1，光丝从中心向外加速（与 `in` 反向），不产生脱出星 |

### 4.2 为什么必须先动画、后清会话

`router.beforeEach` 里有一条：`to.meta.public && authed.value && to.name === 'login'` → 重定向回 `/`。**只要 `authed` 还是 true，就跳不到登录页**。

而 `clearSession()` 会同时清空 `navGroups` / `dynamicRoutes`，侧边栏会立刻空掉——所以也不能在动画前清。

结论：**动画期间保持登录态，播完再 `clearSession()` + `replace`**。代价是这 2.75s 内刷新页面仍是登录态，可接受。

### 4.3 与入场共用的东西

- `resolveIdentityAnchor()`：抽名的终点与胶囊收缩的中心都用它，别各算一次
- `sprayIn()`（欢迎链里的吸入粒子）：E1 的抽名与 E3 的汇聚都用它
- `.transit-sky` / 光丝绘制：`WarpTransit` 的 out 模式复用，不新写一套
- 点击拦截：`exitActive` 期间复用 handoff 的 `blockThrough` 思路

## 5. 关键决策

1. **只抽走名字，不留整句**。「下午好，」留在原地到 E3 再被收走——名字才属于「人」，招呼属于「场景」。抽名字才像「你在离开」，抽整句像「页面在退场」。
2. **胶囊先接住，再缩成点**。直接让胶囊缩掉会像「被删掉」；先头像脉冲一下，是「我知道了」，然后才收。
3. **页面收拢而不是淡出**。`scale/translate + 亮度` 三件套一起降，画面像被吸向中心；只降 opacity 会读作「信号断了」。
4. **光点是唯一穿过暗场的东西**。与入场的边界一致：暗场之后，页面本体已经不存在，只有一颗光在飞。
5. **登录页不做二次入场**。`finishExit` 之前 `Login.vue` 已经在暗场里组装完，天幕一抬就直接可操作；再播一遍 intro 会像「退出了两次」。

## 6. 降级与异常

| 条件 | 处理 |
| --- | --- |
| `prefers-reduced-motion` / 视口 < 760 | 跳过整段：`clearSession()` → `replace('/login')`，靠登录页自身的 `intro`（现有逻辑） |
| 动画期间接口 401 / 会话过期 | 全局拦截会强制跳 login：`ExitChain` 监听路由变化，立即 `finishExit({ abort: true })`，暗场 0.18s 淡出后放行 |
| `clearSession` 后 `replace` 被取消 | 停在原地但已无会话：补一次 `location.replace('/login')` 兜底 |
| 用户连点退出 | `beginExit()` 幂等 + 点击拦截（与 handoff 同款） |
| 窄屏（760~1080） | 正常播；抽名的弧线缩短 40%，避免越过视口 |

## 7. 风险

1. **路由守卫反踢**：见 §4.2，顺序错一步就是「点了退出，画面闪回工作台」。必须在 `replace` 前完成 `clearSession`。
2. **粒子汇聚的性能**：E1 + E3 同时有 30 颗左右的粒子，走 canvas（复用欢迎链的 `dust` 层思路），不要 DOM 粒子。
3. **页面收拢影响真实布局**：只动 `transform` 与 `filter`，绝不动 `width/height/opacity` 之外的布局属性；`.bento` 与 `.nav-group` 用 `gsap.set` 批量设 `will-change`，动画后 `clearProps`。
4. **暗场与登录页的时序**：登录页 DOM 必须在暗场**铺满之后**才挂载，否则会看到「亮着的工作台后面有个登录页」。`markExitSwapped()` 只在 `sky.opacity === 1` 之后由 App 层触发。
5. **退出接口慢**：`logout()` 的请求与动画并行，不 `await`；失败只记日志（本地会话已清）。

## 8. 验收

- 帧：E1 抽名 / E3 收拢 / E4 光点 / E5 光丝 / E7 登录页浮现。
- 断言：
  - 动画期间 `location.pathname` 保持 `/dashboard`（不提前跳转）。
  - 动画结束到登录页可见的间隔 < 120ms（暗场接得上，不闪白）。
  - `localStorage` 里的 token 在动画结束后 1 帧内被清除。
  - 整段无横向滚动、无 `(0,0)` 异物。
- 回归：1440 / 1080 / 800 / 684 四档；浅色、深色、reduced-motion。

## 9. 备选（若不采用「收拢」）

- **B1 熄灯**：顶栏先暗、导航次之、卡片最后，整屏依次降亮后切登录页。最稳、最省，但「没有故事」。
- **B2 逆放**：复用欢迎链倒播。工作量看似最小，实际要逐条反转缓动与粒子方向，且容易被看出是倒带。

推荐仍是「收拢」：它和入场共用一套语汇（星、胶囊、暗场、光丝），但叙事方向相反，读起来是两条独立的动效，不是一条动效的两次播放。
